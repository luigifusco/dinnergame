# Dinner games

Games to play around a dinner table. Each game keeps its rules, cards, and
tooling in its own folder.

| Game | Status | What happens |
|---|---|---|
| [Sideplot](sideplot/README.md) | Playable; printable PDFs included | Everyone carries out secret missions and quirks during ordinary dinner conversation. |
| [Rising Stakes](rising-stakes/README.md) | Concept draft; printable ingredient cards included | Everyone bakes their own focaccia, topped with ingredient cards won in minigames, gambled, or traded. |

Run each game's card generator and tests from its own folder, as described in
the [Sideplot](sideplot/README.md#generate-the-pdfs) and
[Rising Stakes](rising-stakes/README.md#generate-the-pdfs) READMEs.
