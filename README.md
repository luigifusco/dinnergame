# Dinner games

Games to play around a dinner table. Each game keeps its rules, cards, and
tooling in its own folder.

| Game | Status | What happens |
|---|---|---|
| [Sideplot](sideplot/README.md) | Playable; printable PDFs included | Everyone carries out secret missions and quirks during ordinary dinner conversation. |
| [Rising Stakes](rising-stakes/FOCACCIA_PLAN.md) | Concept draft | Everyone bakes their own focaccia, topped with ingredient cards won in minigames, gambled, or traded. |

Run Sideplot's card generator and tests from the `sideplot` folder, as described
in its [README](sideplot/README.md#generate-the-pdfs).
